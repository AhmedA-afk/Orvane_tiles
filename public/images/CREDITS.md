## Renders (`public/renders/`)

Rendered for this project with three.js from the CC0 tile scans above (`scripts/render-stills.mjs`). The path-traced room (`room-day.jpg`) is lit by the [kloofendal_48d_partly_cloudy_puresky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) HDRI by Greg Zaal and Jarod Guest, Poly Haven (CC0), kept in `src/render/hdr/`.

## Interiors (`public/images/interiors/`)

AI-generated for this demo with the OpenAI Codex CLI (and, for one image, Google Antigravity's image tool), each from one of the range's rendered surfaces attached as the reference, following `docs/imagery.md`. The rooms and houses are fictional. The site labels them as AI-generated wherever they appear (`DEMO.imagery`). The shot list is `src/data/range/interiors.json`.

## 3D models (`public/models/`)

- `mid_century_lounge_chair`, `potted_plant_02`, `potted_plant_04`, `modern_ceiling_lamp_01`, `modern_wooden_cabinet`, `ceramic_vase_02`, `ceramic_vase_04`: Poly Haven (CC0), fetched with `scripts/fetch-models.mjs`. The sofas, stone tables, island, bath, bed, loungers and the rest of the Studio's furniture are modelled in code (`src/studio/rooms3d.tsx`).

## The Studio (`public/images/studio/`)

- `empty-room.jpg`: the photo tool's sample room, AI-generated for this demo with the OpenAI Codex CLI. The room is fictional. The Studio's photographs are path traced in the visitor's browser and lit by the same Poly Haven HDRI as the renders.
